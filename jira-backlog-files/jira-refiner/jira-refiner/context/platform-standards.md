# Platform standards (made-up sample)

This file is a made-up sample. On the Fed side the context repo is the program metrics repo.

## Database encryption

Databases that hold program data are encrypted at rest. Check how a database is encrypted before
changing it, and plan a test environment first.

## Dashboards

A dashboard names its audience and the numbers it shows. Keep one dashboard per question.

## Alerts

An alert says what failed and who should look. Alerts that nobody reads are removed.
